# Presentation design

Use conclusion-led titles and one dominant idea per slide. Select layouts semantically, retain native PowerPoint text/tables/charts, and use SVG only for visuals native PPT cannot express well. Do not shrink text to hide excessive content; split the slide.

Use `../artifact-generation/references/workflow.md` and `references/slides.md`.
