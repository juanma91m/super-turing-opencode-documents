# Chart rules

- Time → line; category comparison → bar; correlation → scatter; composition → stacked bar.
- Pie only for a meaningful whole with few categories; use bars above roughly five categories.
- Bars start at zero unless an explicit, justified exception is disclosed.
- Avoid 3D, gauges, rainbow palettes, dual axes and decorative donuts by default.
- Minimize gridlines, label units, retain precision and highlight only evidence supporting the insight.
- Missing data stays missing; never interpolate or invent it silently.
