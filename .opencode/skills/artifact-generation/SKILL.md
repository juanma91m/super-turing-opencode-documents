# Artifact generation

Apply `references/workflow.md`. Start from audience and decision purpose, create a sourced `DocumentSpec`, validate it, render locally, run structural and visual QA, fix material findings, and publish only the reviewed artifact.

Never bypass `DocumentSpec`, templates or QA. Keep semantic content independent from renderer coordinates.

Load `form-design` when the artifact is a form, evaluation, worksheet or checklist. Reuse durable visual preferences only when their recorded context matches the current document.
